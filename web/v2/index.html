How the run works, and how to run it.

  1. Shadow

    The agent pays three suppliers, funds payroll on the first, and tops up USDC through a router on the fifth, for 182 simulated days, under a policy wide enough to let it work. Every call lands on chain through the account with a hash of the instruction behind it.

  2. Export

    The intent trail is read back from the chain's IntentExecuted events, each transaction decoded, and the prompt log joined to it on the intent hash. Nothing in the compiler sees the agent's code.

  3. Compile

    Bounds come from what the agent never exceeded. Habits come from the nyaya synthesiser, the same search that learns game rules and phone-message rules, pointed at (context, payee) and (payee, amount). A rule survives only with at least four cases and 90% precision, re-scored against everything.

  4. Apply and measure

    The policy is written to a fresh agent key with owner-only calls. The held-out calls are replayed at their original spacing, then ten attacks. Coverage and catch rate come from the chain, not from the compiler's opinion of itself.

What this run does not show.

  • The trail is simulated. Seeded, regular, and friendlier than a real ledger. A real agent's six months will have exceptions the bounds would refuse, and coverage below 100% is the expected result there, not a defect.
  • Shadow mode is not zero policy. Rein needs a payee list to run at all, so the owner listed everyone the agent might pay. The compiler still had to find the list, the ceilings and the habits on its own.
  • Learned habits are monitor-only. Time of day and per-payee amounts are not in the contract today. Putting them there is the v2 contract work, and it is not done.
  • Headroom is a choice. 25% above the observed hourly maximum. Less headroom, more refusals of honest calls; more headroom, a larger loss when the payee list is wrong. The number is a dial, and it is printed, not hidden.
  • Local chain. This run is on the in-process Hardhat network. The account contract is the same bytecode that is verified on Base Sepolia and Whitechain Sepolia.
